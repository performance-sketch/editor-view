Gerador de HTML para OBS

Cole os 6 links do YouTube abaixo. O gerador cria o código completo em uma grade 3×2, com autoplay, mudo e controles ocultos.

Código HTML gerado

Manual: do link do YouTube até o OBS Studio

Siga este passo a passo sempre que quiser criar ou atualizar o painel com as câmeras do YouTube.

1

Abra este gerador

Dê dois cliques neste arquivo HTML. Ele abrirá no seu navegador (Chrome, Edge ou outro navegador).

2

Cole os links do YouTube

Cole um link em cada campo: URL 1, URL 2, URL 3, URL 4, URL 5 e URL 6. Você pode usar links normais do YouTube, por exemplo: https://www.youtube.com/watch?v=XXXXXXXXXXX

3

Clique em “Gerar código”

O gerador converterá automaticamente os links para o formato correto de incorporação do YouTube e criará o HTML completo no campo “Código HTML gerado”.

4

Copie o código

Clique no botão “Copiar código”. Se o navegador bloquear a cópia automática, clique dentro do campo do código, pressione Ctrl + A e depois Ctrl + C.

5

Abra o Bloco de Notas

No Windows, pesquise por Bloco de Notas no menu Iniciar e abra um novo arquivo em branco.

6

Cole o código

Dentro do Bloco de Notas, pressione Ctrl + V. Todo o HTML gerado deverá aparecer no arquivo.

7

Salve como arquivo HTML

No Bloco de Notas, clique em Arquivo → Salvar como.

  • Nome sugerido: cameras_obs.html
  • Tipo: Todos os arquivos
  • Codificação: UTF-8
  • Salve em uma pasta fácil de localizar.
8

Abra o OBS Studio

Abra a cena em que deseja exibir as câmeras. Na área Fontes, clique no botão +.

9

Adicione uma Fonte de Navegador

Escolha Navegador / Browser, crie uma nova fonte e dê um nome como Monitor de Câmeras.

10

Selecione o arquivo HTML

Marque a opção Arquivo local e clique em Procurar. Selecione o arquivo cameras_obs.html que você salvou.

11

Configure o tamanho no OBS

Para usar o layout em 4K, utilize:

Configuração Valor
Largura 3840
Altura 2160
FPS personalizado 30 ou 60
12

Confirme e carregue as câmeras

Clique em OK. O OBS carregará o HTML e os seis players aparecerão automaticamente. Os vídeos são configurados para iniciar mutados e sem os controles tradicionais do player.

13

Para trocar uma câmera depois

Você não precisa reconstruir tudo manualmente. Volte a este gerador, troque apenas o link desejado, clique em Gerar código, copie o novo HTML e substitua o conteúdo do seu cameras_obs.html.

14

Atualize no OBS

Depois de salvar a alteração no arquivo, volte ao OBS. Abra as propriedades da Fonte de Navegador e use a opção Atualizar cache da página atual, ou desative e ative novamente a fonte para forçar o recarregamento.

Dica: mantenha sempre o arquivo cameras_obs.html no mesmo local. Assim você pode atualizar apenas o conteúdo do arquivo e o OBS continuará apontando para o mesmo endereço, sem precisar recriar a fonte.
Importante: algumas transmissões do YouTube podem bloquear reprodução incorporada. Se uma câmera não carregar no OBS, teste o mesmo link diretamente no YouTube e verifique se o proprietário permite reprodução em sites externos.
