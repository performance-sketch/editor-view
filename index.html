Manual: do link do YouTube até a tela final

Siga este passo a passo sempre que quiser criar ou atualizar o painel com as câmeras do YouTube. Não é preciso instalar nada — nem o OBS é obrigatório, só entra em cena se você quiser transmitir ou gravar esse painel.

1

Abra este gerador

Acesse https://performance-sketch.github.io/editor-view/ pelo navegador (Chrome, Edge ou outro).

2

Cole os links do YouTube

Cole um link em cada campo: URL 1, URL 2, URL 3, URL 4, URL 5 e URL 6. A URL 1 deve ser o link do Windy para o mapa do tempo, por exemplo: https://www.windy.com/?-22.980,-43.212,11. As demais (URL 2 a URL 6) devem ser links normais do YouTube, por exemplo: https://www.youtube.com/watch?v=XXXXXXXXXXX

3

Clique em “Gerar link”

O gerador converte automaticamente os links para o formato correto de incorporação e preenche o campo “Link direto” acima com um endereço único para esse conjunto de câmeras.

4

Use o link

Clique em “Abrir link” para ver o painel funcionando direto no navegador (nenhum programa extra é necessário), ou em “Copiar link” para enviar esse endereço para quem vai usá-lo — por exemplo, colar em uma TV, num monitor dedicado, ou na Fonte de Navegador do OBS.

5

(Opcional) Use no OBS Studio

Se quiser transmitir ou gravar esse painel: abra a cena desejada, na área Fontes clique em +, escolha Navegador / Browser e dê um nome como Monitor de Câmeras.

  • Cole o link no campo URL.
  • Deixe a opção Arquivo local desmarcada.
6

Configure o tamanho (se for usar no OBS)

Para usar o layout em 4K, utilize:

Configuração Valor
Largura 3840
Altura 2160
FPS personalizado 30 ou 60
7

Para trocar uma câmera depois

Volte a este gerador, troque apenas o link desejado e clique em Gerar link novamente. Um novo link é criado — copie-o e cole no lugar do anterior (na TV, no monitor, ou nas propriedades da Fonte de Navegador do OBS). Não é preciso salvar, importar ou reconstruir nenhum arquivo.

Dica: o link gerado já é permanente e público — pode favoritar, enviar por WhatsApp ou deixar aberto em qualquer tela. Ele só muda quando você gera um novo link com câmeras diferentes.
Importante: algumas transmissões do YouTube podem bloquear reprodução incorporada. Se uma câmera não carregar, teste o mesmo link diretamente no YouTube e verifique se o proprietário permite reprodução em sites externos.
